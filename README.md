# ✨ 星辰大学智慧校园网络设计 —— 关键技术介绍

> 本次网络升级采用**三层架构 + 主流网络技术**，构建高可靠、高安全、易扩展的智慧校园网络。

---

## 📌 核心技术一览表

| 技术 | 全称 / 类型 | 主要作用 | 应用场景 |
|------|-------------|----------|----------|
| **VLAN** | 虚拟局域网 | 逻辑隔离广播域，提升安全性与管理效率 | 按楼宇划分网络（实验楼、宿舍区等） |
| **DHCP** | 动态主机配置协议 | 自动分配 IP 地址、网关、DNS | 师生终端免配置接入网络 |
| **OSPF** | 开放最短路径优先 | 动态路由，基于链路状态计算最优路径 | 核心层与汇聚层路由互通 |
| **Eth-Trunk** | 链路聚合 | 捆绑多条物理链路，提高带宽与冗余 | 核心与汇聚设备之间链路聚合 |
| **VRRP** | 虚拟路由冗余协议 | 实现网关热备切换，保障高可用 | 汇聚交换机网关冗余 |
| **MSTP** | 多生成树协议 | 消除二层环路，支持多 VLAN 负载分担 | 接入层与汇聚层环路避免 |
| **WLAN** | 无线局域网 | 实现无线终端接入 | AC + AP 集中管理，校园无线全覆盖 |
| **IPsec VPN** | IP 安全隧道 | 建立加密隧道，实现跨校区安全互访 | 主校区与分校区互通 |
| **SLB** | 服务器负载均衡 | 流量均衡分发至多台服务器 | DNS / WEB 服务器业务分担 |
| **NAT** | 网络地址转换 | 私网 IP 转公网 IP，访问互联网 | 校园网出口上网控制 |
| **Telnet** | 远程登录协议 | 远程配置与管理网络设备 | 运维人员集中管理设备 |

---

## 🧩 关键技术详解

### 1️⃣ VLAN + DHCP —— 动态隔离与自动接入

- **VLAN**：将实验楼、教学楼、宿舍区等划分为独立 VLAN（如 VLAN 100 / 200 / 400），隔离广播域，提高安全性。
- **DHCP**：每个 VLAN 对应一个 DHCP 地址池，终端自动获取 IP，无需手动配置。

示例：VLAN 100（实验楼）
